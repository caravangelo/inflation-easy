InflationEasy v1.1.3 release candidate

This candidate prepares a documentation update to v1.1.2 (baseline commit
f1d2574124cb4be54f142a47dc80be850286e3f2). Source comments and the developer
guide explain evolution stages, variables, units, approximations, numerical
operators and diagnostics. Numerical algorithms, input tables and output
formats are unchanged. Citation metadata identifies this as 1.1.3-rc.1.

Start with README.md for installation and examples. Build with make and run
make test for spatial-operator, input-table and smoke checks. The MIT licence
is in LICENSE. For source documentation, begin with
src/evolution/evolution_internal.h and DEVELOPER_GUIDE.md.

This is a candidate, not a published version. The planned final release is
v1.1.3. Its final metadata and release date will be set when publication is
authorized. The candidate archive and commit are recorded in the accompanying
provenance file. No new Git tag or public release has been created.
